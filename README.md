# Face my Ankle (thats a solid ankle)
<sub>Also abbreviated to fma</sub>


Basically, I'm making an ankle monitor.

I'm making an ankle monitor which users can remotely interact with and do stupid stuff.

## The system works like so:

### **The** **Ankle**
This sits at the bottom of the stack, both physically and metaphorically.

It directly handles the hardware/IoT connectivity and provides an interface for the face...speaking of the face

### **The** **Face**
The face sits at the top of the stack, imagine it in the cloud. 

It manages user and client interactions then routes those commands to the Ankle which actually executes the physical actions in the physical world.
